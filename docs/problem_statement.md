# AI-Based Student Performance & Academic Risk Analyzer

## Problem Statement

Educational institutions collect large amounts of student information
such as attendance, study habits, family background, previous failures,
and academic performance.

Manual analysis of these factors can be difficult and time-consuming.

This project uses Artificial Intelligence and Machine Learning techniques
to analyze student-related data and predict academic performance while
classifying students into project-defined academic-risk categories.

## Objectives

1. Collect and preprocess student performance data.
2. Perform exploratory data analysis.
3. Identify useful patterns in student data.
4. Develop a Machine Learning regression model.
5. Predict final student grades.
6. Develop a classification model.
7. Classify students into academic-risk categories.
8. Evaluate model performance.
9. Develop an interactive dashboard.
10. Document the complete project workflow.

## Machine Learning Tasks

### Regression

The regression model predicts the student's final grade.

Target variable:

`G3`

The predicted grade is represented on a scale of 0 to 20.

### Classification

The final grade is converted into project-defined categories:

- At Risk
- Moderate
- Good
- High

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

## Expected Outcome

The final system will provide an interactive interface where student
information can be entered and the Machine Learning models can generate
an estimated final grade and academic-risk category.
